# Grain & Silver — Lucas Vance

Sitio web estático de 8 páginas (más una página de documentación del sistema de diseño). Sin build, sin dependencias: HTML + CSS + un archivo JS pequeño.

## Publicar en GitHub Pages
1. Sube **el contenido de esta carpeta** a la raíz de un repositorio.
2. Settings → Pages → Branch `main` / `(root)` → Save.

## Estructura (Diseño Atómico)
- `css/01-tokens.css` — colores, tipografía, espaciado
- `css/02-atoms.css` — botón, enlace, input, etiqueta, logo…
- `css/03-molecules.css` — tarjetas, campos, acordeón, nav link…
- `css/04-organisms.css` — cabecera, héroe, galerías, formulario, pie
- `css/05-templates.css` — esqueletos de página
- `js/main.js` — carrito, marcadores y formulario (el sitio funciona sin JS)
